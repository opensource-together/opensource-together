[OpenSource Together](https://opensource-together.com) helps open-source projects
find contributors and grow with their communities.

- AI-powered project discovery and recommendation system
- Import repositories from GitHub or GitLab
- Claim ownership of your projects
- Dashboard for projects and activity

## Local development

```bash
git clone https://github.com/opensource-together/opensource-together.git
cd opensource-together
pnpm install
pnpm dev:mock
```

Open [localhost:3000](http://localhost:3000). The repository includes a local,
stateful API with sample data, no private backend, database, Docker, or OAuth
setup required.
